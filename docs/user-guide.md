# 使用说明（开发版，待用户测试）

安装完整客户端，打开后使用 StarRail 账号登录。主备 API 已内置，不需填写域名或复制订阅。同步后首页显示套餐、到期时间、剩余时间、流量和节点；未知信息显示待确认。安全后端可用时加密保存会话，否则仅保留内存会话。

选择“规则”使用大陆直连与代理兜底，选择“全局”代理公网流量并保留必要系统例外。点击连接时，若系统服务缺失会进入系统授权安装流程；已有服务直接准备连接。只有实际 TCP/UDP/DNS/IPv6 检查通过后才显示已连接。失败时清理网络，恢复未完成会提示修复。macOS 的应用须先放入 /Applications。

自动节点模式探测合格候选；手动选择保留你的节点选择。默认 TLS/REALITY 使用 X25519 初始密钥交换，订阅已有有效指纹则继续沿用。开发包允许试连实现支持的协议；不表示运营节点能力已经实测确认。

节点列表可以搜索、选择和手动探测前十项；每批最多四并发，间隔三十秒。显示的 HTTPS 耗时不代表带宽。示例模式不启动代理、不伪造延迟。

官网、帮助和续费使用系统浏览器。续费时核对网页账号；返回客户端或点击刷新后重新同步，完整同步确认新权益。

到期前七天、三天和到期时提供去重通知。设置可调整主题、开机启动、启动后连接、关闭行为；启动相关设置默认关闭。无可靠托盘时关闭窗口会询问退出，退出会清理网络。

“网络组件 → 修复”停止当前连接并修复系统服务，可能需要管理员授权；其他会话持有网络时提示冲突。没有 GUI 时使用 native-service.md 中的独立修复命令。

更新源配置后，设置内可检查、下载、暂停、继续、取消与重试。下载完成后由你选择重启安装。安装前清理网络、再次验证签名和哈希；保留上一版备份并提供中断恢复。当前交付尚未配置运营更新源，因此“检查更新”会提示未配置。

诊断只导出本地版本、时间、平台、错误码和耗时，不自动上传，不含账号令牌、订阅、节点秘密或访问记录。退出账号立即清除本地会话，并尝试移除本次远端会话；网络失败不阻止本地清除。

本轮按用户要求未做运行测试，安装与实际网络行为由用户在目标系统测试。
