# 使用说明

1. 从下载页下载安装包。第一次打开时系统会拦一下：
   - Windows 出现“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
   - macOS 提示“无法验证开发者”或“已损坏”：先把应用拖进“应用程序”，然后打开“系统设置 → 隐私与安全性”，在最下方点“仍要打开”。
2. 用账号邮箱和密码登录。不用复制订阅、不用填域名。
3. 点中间的大按钮连接，按钮变绿就是连上了。默认是“系统代理”模式：浏览器和大多数软件走代理，不需要管理员密码。游戏、命令行等不认系统代理的软件，可以在首页切到“TUN 模式”，它接管所有软件，第一次使用要授权一次（macOS 输入电脑密码，Windows 点“是”）。
4. 下面的“线路”默认是“自动选择”，会一直用最快的线路，线路坏了自动换。想固定某个地区就点进去选。
5. 套餐卡片显示剩余天数和流量。快到期或流量快用完时会变黄，点“续费”打开官网。

国内网站直连，国外网站走代理，广告自动拦截（首页可以关掉“广告拦截”）。系统代理模式下本机代理端口显示在首页，一般是 7890，命令行可以设置 `https_proxy=http://127.0.0.1:7890`。ChatGPT、Claude、Gemini 这类 AI 服务会自动走美国、日本、新加坡等节点，即使你选的是香港。个别网站打不开时，可以在设置里打开“全局代理”试试。

连不上时，按钮下面会说明原因并给出下一步，比如“换个线路”“去续费”“修复”。还是不行就点“设置 → 上报问题”，发送后会显示一个 6 位问题编号，把编号发给客服。上报的内容是连接记录和网络检查结果，不包含浏览记录、密码和订阅链接。

客户端在后台会把连接结果和错误信息发给运营方，用于排查问题，内容范围同上。

关掉窗口后客户端留在托盘里，连接不断。退出时如果是连接状态，下次打开会自动重新连接。有新版本时首页顶部会出现“推荐更新”，点“立即更新”会自动下载、安装并重新打开，不用重新下载安装包。客户端会自动检查更新，不需要设置。

同一产品和环境的跨版本更新会保留本机已保存的登录态、收藏和最近使用的线路；手动覆盖安装也会保留。更新后临时断网不会退出登录。从把登录密钥存在钥匙串的更早 Mac 版本升级时，需要重新登录一次。主动退出登录、服务端令牌失效，或本机登录数据、密钥已被删除时，需要重新登录。

面板暂时连不上（比如域名被墙）时，客户端继续使用上次同步的线路，最多 7 天，且不超过套餐到期时间。
