# 后续接入与用户测试

本轮已实现原生网络服务、实际连接驱动、修复入口和更新安装器。按用户最新指示不运行测试，以下是后续接入与验收工作，安装版不再使用 UnavailableDriver 代替网络实现。

1. 在 Windows 11 x64、macOS 14+ x64/arm64、Ubuntu 24.04 GNOME 安装开发包，用真实账号完成登录、订阅和节点连接。
2. 检查规则/全局、TCP/UDP/DNS/IPv6、网络切换、拒绝授权、断开、睡眠唤醒、核心/GUI/服务强退、多用户冲突、网络恢复和离线修复。
3. 配置策略/规则和更新发布端点、独立 Ed25519 公钥、平台签名/公证身份。项目不会自行编造这些运营资料。
4. 在各平台构建、安装和升级，检查签名、备份、失败回退、中断恢复、卸载及长期运行。macOS DMG 需要 macOS 构建机。
5. 用实测结果填写 72 项验收表和支持矩阵，再开放正式发布门禁。

上一版测试结果不适用于新增原生代码。用户测试发现的问题应按平台、错误码和复现步骤修复。
